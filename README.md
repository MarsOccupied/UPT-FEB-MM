# Mind Map Tool

An interactive mind map tool for organizing life categories using D3.js.

## Features

- Interactive nodes with drag and drop
- Force-directed layout
- Photo attachments
- Dark/light themes
- Project-based saving
- Unlimited zoom and pan

## Installation

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the development server

## Usage

Open the application in your browser and start creating mind maps.

## Technologies

- D3.js for visualization
- Vite for build tool
- HTML5, CSS3, JavaScript
